# Expressions and operations

### **Evaluation**

**Evaluation is the process of computing a final, single value from a combination of data and rules.** The system looks at an expression, performs the math or logic, and boils it down to one result.

- _Example:_ The expression `3 + 5` evaluates to the single value `8`.

### **Operators**

**Operators are the special symbols that tell the system what action to perform on values.** They are the verbs of the system.

- **Arithmetic:** Symbols like `+`, `-`, `*`, `/` (add, subtract, multiply, divide).
- **Comparison:** Symbols like `>`, `<`, `==` (greater than, less than, equal to) used to check relationships.
- **Logical:** Symbols like `AND`, `OR`, `NOT` used to combine true/false conditions.

### **Combining Values**

**Combining values means using operators to link two or more pieces of data together to form a larger idea.** You can combine values of the same type (like adding two numbers) or sometimes different types (like gluing two pieces of text together).

- _Example:_ Combining `"Space "` + `"Cat"` creates a new combined text value: `"Space Cat"`.

### **Precedence**

**Precedence is the set of priority rules that determines the order in which operators are calculated.** Just like standard math rules, certain operations must happen before others unless you use parentheses to force a different order.

- _Example:_ In `2 + 3 * 4`, multiplication has higher priority than addition, so it evaluates to `14`, not `20`.

### **Side Effects**

**A side effect occurs when evaluating an expression changes the system's state outside of the final calculated result.** It means the operation did its math, but _also_ permanently altered something in the background.

- _Example:_ An operation that calculates a player's new score but _also_ automatically saves the game to the hard drive at the same time.

### **Expressions vs. Statements**

The easiest way to tell them apart is whether they result in a value or perform an action:

- **Expressions:** Pieces of code that **always result in a value**. They ask a question or perform a calculation.
- **Statements:** Complete instructions that **execute an action** or command. They change state or control the flow, but do not result in a value on their own.

|Concept|Primary Purpose|Analogy|Example|
|---|---|---|---|
|**Expression**|To calculate a value.|A question.|`5 + 5` (Results in `10`)|
|**Statement**|To perform an action.|A command.|"Store the number 10 in the box."|
