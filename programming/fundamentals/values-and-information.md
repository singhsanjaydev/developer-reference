# Values and information

### What is Data?

**Data is a raw collection of facts, figures, or symbols** before they are given any meaning or context. Think of data as the raw ingredients (like flour, sugar, and eggs) and information as the finished cake.

### **Values**

**A value is a single, specific piece of data** that represents a concrete concept at a given moment.

- _Example:_ `42`, `"Hello"`, or `True` are all values.

### Types of Values (Conceptual)

In logic and computation, values are grouped into categories based on what kind of real-world information they represent:

- **Numbers:** Used for counting or measuring. This includes whole numbers (integers like `5`) and fractional numbers (decimals like `3.14`).
- **Text / Characters:** Letters, words, or sentences used to display human language (like `"cat"` or `"A"`).
- **Booleans (Logic):** A binary choice that can only be either **True** or **False** (like a light switch being on or off).
- **Collections:** A group of multiple values bundled together, like a shopping list or a grid of numbers.

### **State**

**State is the snapshot of all stored information** in a system at an exact point in time. If you pause a video game, the current score, player position, and remaining health make up the game's "state."

### **Constants vs. Changing Values**

- **Constants:** Values that **cannot change** once they are set. They represent fixed truths.
    - _Example:_ The value of Pi (\(\pi \)) or your birthdate.
- **Changing Values (Variables):** Storage places for data where the value **can be updated** as time goes on.
    - _Example:_ Your current age, the temperature outside, or a game score.

### **Representation of Information**

**This is how real-world ideas are converted into a format a system can store and process.**  
Systems cannot directly understand a "color" or a "sound." Instead, we represent them using agreed-upon codes. For example, the color red might be represented by a specific code of numbers, and the letter "A" is represented by a specific numeric value behind the scenes.
